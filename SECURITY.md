# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

- Preferred: use GitHub private vulnerability reporting on the affected repository
  (for `core`: <https://github.com/capybara-hq/core/security/advisories/new>).
- Alternative: email 284885069@qq.com.

We reply to every report within 2 days to say it was received and is being assessed.
We do not promise a fixed time to a fix; it depends on severity.

## Supported versions

| Version | Security fixes |
|---|---|
| Before 1.0 | Latest release only |

Fixes ship in the next release. We do not backport.

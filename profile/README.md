# Capybara

**The calm agent that plugs into every system in your company and gets the work done.**

情绪稳定地接入企业内的所有系统，帮你把工作处理好。

Capybara is an open-source enterprise agent platform. The kernel is deliberately small: it only
handles config, the database, plugin hosting and HTTP. Every capability, such as model providers,
tools, sandboxes, connectors and chat channels, is delivered as a plugin. It is written in
TypeScript and licensed under Apache-2.0.

## Repositories

| Repository | What it is |
|---|---|
| [core](https://github.com/capybara-hq/core) | The kernel, the CLI, the web app, the plugin SDK and the official plugins |
| plugins | A separate plugins repository, coming after M7 |
| [.github](https://github.com/capybara-hq/.github) | Organization-wide community files, shared workflows and agent skills |
